# Raw inputs

Evidence, verbatim. The user's own words, screenshots, pasted errors,
transcripts, external references.

## Rules

- **Never edit a file in here.** If an input is wrong or superseded, add a new
  one that says so. Evidence you can rewrite is not evidence.
- Name files `YYYY-MM-DD-slug.md`. Binary assets go in `assets/` with the same
  date prefix.
- Record the source and date at the top of every file: who said it, when, in
  what context.
- Quote rather than paraphrase. Paraphrase belongs in the synthesis layer,
  where it can be corrected.
- If an input contradicts something in `architecture.md`, `domain.md`, or
  `state.md`, the input is probably right — fix the synthesis and note it in
  the journal.
